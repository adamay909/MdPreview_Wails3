# Markdown Previewer

This is a desktop application created as an exercise to familiarize myself
with Wails3.

## Functionality

 It can do one thing: preview Markdown documents. I use it preview markdown
documents while editing in Vim. 

- You can open multiple files at once in separate windows. You can even open the
  same window multiple times.
- Changes in the markdown file will be reflected as soon as they are saved to
  disk.
- You can change the font between Serif and Sans Serif from the View menu. 
- You can zoom in and out from the View menu (or the usual keyboard shortcuts).
- Dark mode is supported.
- From the Edit menu, you can copy with one click the whole document with rich
  formatting for pasting into editors that don't understand Markdown. You can
also copy the HTML as plain text so you can paste that into editors, and you can
also copy the original Markdown if you want. You can of course also do the usual
select and copy.

## Installation

Get [Wails3](https://v3.wails.io/) and follow the instructions there to build
this.
